# 毛豆高空协同捉虫系统——分阶段技术实施方案

> 目标作物：毛豆（矮秆作物，株高 30-90cm，底荚高度 7-11cm）
> 实施顺序：地面站 → 地面机器人 → 无人机（受物流到货时间决定）

## 一、方案概述

### 1.1 为什么选择毛豆？

毛豆（大豆）是矮秆作物，株高通常在 30-90 厘米，结荚部位低（底荚高度 7-11 厘米）。SpiderPi Pro 的 40cm 机械臂可以轻松覆盖从地面到植株中上部的全部作业区域，这是选择毛豆作为目标作物的核心原因——让机械臂从"短板"变成"长板"。

### 1.2 核心虫害目标：豆荚螟

豆荚螟是毛豆最主要的虫害之一，幼虫钻入豆荚内部取食豆粒，危害具有隐蔽性。视觉识别的目标是发现豆荚表面的微小蛀孔、变色或异常形态，进而引导机器人精准摘除受害豆荚。

### 1.3 实施顺序说明

由于物流问题，设备到达时间不同，采用"地面站先行 → 地面机器人跟进 → 无人机最后集成"的分阶段推进策略。每个阶段完成后，下一个阶段可以在已有基础上叠加，最终形成完整系统。

> 开发节奏按步骤推进，不按周硬性排期：每完成一步立即进入下一步，设备到位即可开始对应部分。

## 二、第一阶段：地面站搭建

### 2.1 阶段目标

完成核心计算平台的建设，为后续机器人控制和无人机通信打下基础。

> 本阶段实际操作请按 [GroundStation/开始配置.md](GroundStation/开始配置.md)
> 执行（**Windows 地面站方案**：机械革命笔记本 + RTX 5060 8G，调用 NVIDIA GPU
> 加速 YOLO；无人机数据用 pymavlink 读 MAVLink，不再使用 Ubuntu/ROS）。

### 2.2 硬件准备

| 设备 | 型号 | 说明 |
|------|------|------|
| 地面站PC | 机械革命笔记本（RTX 5060 8G / 32G内存 / 1TB固态） | NVIDIA 显卡，用于 YOLO 加速（Windows 10/11） |
| 无线路由器 | 双频千兆路由器 | 建立本地局域网 |

### 2.3 软件环境搭建

**第一步：安装 NVIDIA 驱动（Windows）**

在 Windows 下安装 NVIDIA 驱动最简单（无内核问题），装完用 `nvidia-smi` 验证
能看到 RTX 5060 Laptop GPU。

**第二步：安装 Python + YOLO 依赖（CUDA 版）**

```bat
python -m pip install --upgrade pip
python -m pip install ultralytics opencv-python
python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
```

> RTX 5060 是 Blackwell（sm_120），torch 必须装 `+cu128` 版（2.7+），
> 否则报 `sm_120 not compatible`。

**第三步：安装 QGroundControl**（无人机地面站）

QGC 是 Windows 原生软件；数传 UDP 8080 连接、RTSP 图传，见
[Dron/开始配置.md](Dron/开始配置.md)。

**第四步：安装 pymavlink**（替代 MAVROS 读无人机数据）

```bat
python -m pip install pymavlink
```

直接读 MAVLink 消息（位置/姿态/电量），不需要 ROS。

> 完整步骤、防火墙放行、验收命令见
> [GroundStation/开始配置.md](GroundStation/开始配置.md)。

## 三、第二阶段：地面机器人开发

### 3.1 阶段目标

完成 SpiderPi Pro 的单机开发，实现"自主行走 + 视觉识别 + 机械臂抓取"的基础功能，为后续与无人机协同做准备。

### 3.2 硬件准备

| 设备 | 型号 | 参考价格 |
|------|------|----------|
| 地面机器人 | 幻尔 SpiderPi Pro（树莓派4B/4GB） | ¥5,700 |

SpiderPi Pro 以树莓派 4B 为主控，搭载 5DOF 机械臂（20kg·cm 总线舵机）、超声波传感器、IMU 姿态传感器。

### 3.3 开发路线

开发按步骤顺序推进，完成一步立即进入下一步，不按周排期。

**第一步：基础环境配置**

> 本阶段实际操作请按 [GroundRobot/开始配置.md](GroundRobot/开始配置.md) 执行。

1. **开机与连接**
   - SpiderPi Pro 出厂默认为 AP 直连模式，开机后会产生以 "HW" 开头的热点
   - 电脑连接该热点，通过 VNC Viewer 连接树莓派桌面（默认 IP: 192.168.149.1）

2. **熟悉目录结构**
   - SpiderPi Pro 的所有 Python 源码均开放，包含详细注释
   - 源码位于 `~/spiderpi/` 目录下

**第二步：基础运动调试**

3. **六足行走测试**
   - 运行基础行走 Demo，熟悉六足机器人的运动控制
   - 测试在不同地形（平地、草地、轻微坡道）上的行走稳定性

4. **机械臂调试**
   - 学习机械臂正逆运动学基础
   - 逐一测试 5 个舵机的运动范围和精度

**第三步：视觉识别开发**

5. **摄像头调参与位置校准**
   - 完成摄像头位置校准
   - 调整颜色阈值，适应毛豆田的环境光照

6. **目标识别模型部署**
   - 在地面站 PC 上训练 YOLO 模型识别豆荚螟危害特征（蛀孔、变色豆荚）
   - 将模型轻量化后部署到树莓派端（或通过 Wi-Fi 调用地面站 API）

**第四步：抓取功能开发**

7. **色块定点夹取测试**
   - 运行官方 Demo `block_fetch.py`，测试"识别→移动→夹取"的完整流程

8. **毛豆模拟抓取**
   - 用绿色色块或真实毛豆植株模拟目标
   - 调整机械臂抓取参数，适配毛豆豆荚的尺寸和位置（离地 7-11cm）

### 3.4 关键技术点：机械臂控制

SpiderPi Pro 的机械臂通过树莓派扩展板的 I2C（地址 0x7A）与树莓派通信，再由 STM32 串口输出总线舵机协议驱动 HTS-20H 舵机。控制代码采用 Python 编写：

```python
# 机械臂控制示例（基于幻尔官方SDK）
from common.ros_robot_controller_sdk import Board
import arm_ik.arm_move_ik as AMK

# 初始化控制板
board = Board()
# 设置机械臂目标姿态（逆运动学求解）
AMK.set_arm_pose(x, y, z, roll, pitch, yaw)
```

## 四、第三阶段：无人机集成

### 4.1 阶段目标

将 F410 无人机接入系统，实现"无人机侦察→地面站处理→机器人抓捕"的完整协同闭环。

### 4.2 硬件准备

| 设备 | 型号 | 参考价格 |
|------|------|----------|
| 无人机 | 阿木实验室 F410（含Pixhawk 6C、数传、电池、遥控器） | ¥5,648 |

F410 是一款 410mm 轴距的四旋翼开源无人机平台，搭载 Pixhawk 6C 开源飞控（STM32H743 处理器），标配 M8N GPS+光流测距一体模组。整机空载重量 1056g，最大起飞重量 2.2kg，标准悬停续航 21 分钟。

### 4.3 开发路线

无人机部分同样按步骤推进，完成一步立即进入下一步。

**第一步：无人机基础调试**

> 本阶段实际操作请按 [Dron/开始配置.md](Dron/开始配置.md) 执行（F450 V6C
> 官方手册整理版，含开箱、充电、开机、数传、校准、首次飞行）。

1. **开箱检查与组装**
   - 按照 F410 使用手册完成组装
   - 检查所有电机、电调、飞控连接

2. **QGroundControl 地面站配置**
   - 安装 QGroundControl
   - 通过 USB 连接飞控，检查固件版本（出厂预装 PX4 v1.15.4）
   - 校准加速度计、罗盘、遥控器

3. **遥控器对频与试飞**
   - 完成遥控器与接收机对频
   - 在安全区域进行低空悬停测试

**第二步：pymavlink 通信配置**（Windows 地面站读 MAVLink，替代 MAVROS）

4. **飞控端参数设置**
   - 在 QGroundControl 中，将 `MAV_1_CONFIG` 设置为 TELEM2
   - 设置 `MAV_1_RATE` 为 80000
   - 重启飞控

5. **地面站端 pymavlink 配置**
   - 地面站监听 UDP 14550（QGC 用 8080），连接串
     `udpin:0.0.0.0:14550`；USB 直连时用串口 `COM3,57600`
   - 脚本示例见 [Dron/教学/MAVLink与MAVROS.md](Dron/教学/MAVLink与MAVROS.md)

6. **通信测试**
   - 通过数传（Minihomer）连接飞控与地面站
   - 运行 `python D:\yolo\scripts\read_drone.py`
   - 能打印位置/GPS/电量即通过

**第三步：视频传输配置**

7. **机载摄像头推流**
   - F410 标配机载摄像头
   - 在无人机端（或通过机载伴侣电脑）使用 GStreamer 推流：

```bash
# 无人机端推流（H.264编码，UDP传输）
gst-launch-1.0 v4l2src device=/dev/video0 ! video/x-h264,width=1280,height=720,framerate=30/1 ! \
  h264parse ! rtph264pay ! udpsink host=地面站IP port=5000
```

8. **地面站接收**

```bash
# 地面站接收
gst-launch-1.0 udpsrc port=5000 ! application/x-rtp,encoding-name=H264 ! \
  rtph264depay ! h264parse ! avdec_h264 ! autovideosink
```

**第四步：YOLO 目标检测集成**

9. **实时检测管线搭建**
   - 将接收到的视频帧送入 YOLO 模型
   - 针对毛豆豆荚螟危害特征进行检测（蛀孔、变色豆荚）

10. **坐标计算与下发**
    - 检测到目标后，读取无人机 GPS/光流定位数据
    - 计算目标全局坐标
    - 通过 HTTP POST 将坐标下发给 SpiderPi Pro（格式见 YOLO 教学文档 7.3）

## 七、关键技术风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| Wi-Fi信号不稳定 | 视频中断、控制延迟 | 使用5.8GHz频段；地面站与设备尽量近距摆放 |
| 无人机续航不足 | 无法完成多次侦察 | 准备备用电池；优化航线缩短飞行时间 |
| YOLO识别准确率低 | 目标漏检、误检 | 收集毛豆豆荚螟实景图像扩充数据集 |
| 机械臂抓取失败 | 任务无法完成 | 先用色块模拟训练，再过渡到真实豆荚 |
| 坐标对齐误差 | 机器人找不到目标 | 无人机悬停时多次测量取平均；机器人到达后视觉二次确认 |

## 八、总结

本方案按照"地面站 → 地面机器人 → 无人机"的顺序分阶段推进，每个阶段独立可验收，最终形成完整的空地协同捉虫系统。针对毛豆（矮秆作物，结荚高度 7-11cm）的特点，SpiderPi Pro 的 40cm 机械臂可以轻松覆盖作业区域，使"侦察→定位→抓捕"的协同逻辑更加顺畅。总预算控制在 ¥18,748，在 2-3 万元范围内。
