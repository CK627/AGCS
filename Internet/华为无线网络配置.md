# 华为无线网络配置（单独手册）

> 本手册只讲 **华为** 设备。网络配置是基础设施，不优先；先读懂
> [通信协议规范.md](通信协议规范.md)，再按本手册配置。
>
> 适用设备：华为 AirEngine 系列 AP（Fat 独立模式）或 AC + AirEngine Fit AP。
> 命令以常见版本为例，实际以 `display version` 和产品手册为准。

## 1. 拓扑与规划

```text
            ┌──────────────────────────────┐
            │  华为 AP / AC（业务网）       │
            │  VLAN 200：192.168.1.0/24    │
            └───┬───────────┬───────────┬──┘
       有线/5G │      5GHz │       有线 │
   ┌──────────▼───┐ ┌──────▼──────┐ ┌───▼──────────────┐
   │ 中枢地面站     │ │ SpiderPi Pro│ │ Minihomer 基站    │
   │ 192.168.1.100│ │ 192.168.1.101│ │ 192.168.1.123   │
   └──────────────┘ └─────────────┘ └──────────────────┘
```

| 项目 | 值 |
|------|-----|
| 管理 VLAN | 100，`192.168.100.0/24` |
| 业务 VLAN | 200，`192.168.1.0/24` |
| 业务网关 | `192.168.1.1` |
| 5GHz SSID | `AGCS-5G` |
| 2.4GHz SSID | `AGCS-2.4G` |
| 安全 | WPA2-PSK / AES |
| 固定 IP | 地面站 `.100`、机器人 `.101`、Minihomer `.123`、图传 `.10` |

## 2. Fat AP 独立模式配置

```text
system-view
sysname AGCS-AP1
vlan batch 100 200

interface Vlanif100
 ip address 192.168.100.11 255.255.255.0
 quit

interface Vlanif200
 ip address 192.168.1.1 255.255.255.0
 dhcp select interface
 dhcp server dns-list 223.5.5.5
 quit

wlan
 security-profile name agcs-sec
  security wpa2 psk pass-phrase AGCS-2026 aes
  quit

 ssid-profile name agcs-5g
  ssid AGCS-5G
  quit
 ssid-profile name agcs-24
  ssid AGCS-2.4G
  quit

 vap-profile name agcs-5g-vap
  forward-mode direct-forward
  service-vlan vlan-id 200
  ssid-profile agcs-5g
  security-profile agcs-sec
  quit
 vap-profile name agcs-24-vap
  forward-mode direct-forward
  service-vlan vlan-id 200
  ssid-profile agcs-24
  security-profile agcs-sec
  quit

 ap-group name default
  radio 0
   vap-profile agcs-24-vap wlan 1
  radio 2
   vap-profile agcs-5g-vap wlan 1
  quit
quit
save
```

## 3. DHCP 静态绑定

```text
system-view
interface Vlanif200
 dhcp server static-bind ip-address 192.168.1.100 mac-address <地面站MAC>
 dhcp server static-bind ip-address 192.168.1.101 mac-address <机器人MAC>
 quit
save
```

## 4. AC + Fit AP 方案

AC 集中管理时，管理 VLAN 和业务 VLAN 同样在 AC 上创建；AP 通过 MAC 认证或
序列号上线后，把上面的 SSID/VAP 绑定到 AP 组即可：

```text
display ap all
display ap-id 0 verbose
```

AP 自身不需要配置业务 IP，由 AC 统一下发。

## 5. Web/云管理路径

1. 管理电脑临时设置 `192.168.100.10/24`，登录设备管理地址；
2. 华为：`网络 → 无线业务 → SSID/VAP`；
3. 创建 VLAN、DHCP、SSID，选择 `WPA2-PSK/AES`；
4. 给 AP 供电/上联，确认 AP 在线；
5. 保存配置，手机扫描 SSID 验证。

## 6. 验证与排障

```text
display ap all
display current-configuration
```

| 现象 | 排查 |
|------|------|
| AP 不上线 | PoE 供电、AC 与 AP 的 VLAN 放通、授权是否正确 |
| 连上 SSID 拿不到 IP | DHCP 地址池、业务 VLAN 是否绑定 |
| 拿到 IP 但 ping 不通 | 网关、交换机端口 VLAN、无线隔离是否误开 |
| 5G 延迟高 | 避开 DFS 信道，优先 36/40/44/48 |
