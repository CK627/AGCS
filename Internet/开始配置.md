# 网络协议（Internet）新手开始配置

> 给新手的入口文档。原则只有一句：**先看懂拓扑，先跑通通信协议，再配设备**。
>
> 三份文档分工：
>
> - [通信协议规范.md](通信协议规范.md)：最优先，无人机/机器人/中枢怎么通信；
> - [H3C无线网络配置.md](H3C无线网络配置.md)：H3C 设备单独配置；
> - [华为无线网络配置.md](华为无线网络配置.md)：华为设备单独配置。
>
> 本文档只讲"三台设备、一张网络、先干什么"。

## 1. 一张简单拓扑

```text
                     ┌───────────────────────────────┐
                     │ 无线/交换网络                   │
                     │ 业务网段 192.168.1.0/24        │
                     └───┬──────────┬──────────┬─────┘
                 有线/5G │     5GHz │      有线 │
        ┌──────────────▼───┐ ┌────▼──────────────┐ ┌────▼──────────────┐
        │ 中枢地面站        │ │ 地面机器人         │ │ Minihomer 基站    │
        │ 192.168.1.100    │ │ SpiderPi Pro      │ │ 192.168.1.123     │
        │                  │ │ 192.168.1.101     │ │                   │
        └────────┬─────────┘ └────────▲──────────┘ └────┬──────────────┘
                 │   HTTP :5000       │                 │ 无线链路
                 └────────────────────┘                 ▼
                                          ┌─────────────────────────┐
                                          │ 无人机 F450 V6C          │
                                          │ 图传 192.168.1.10       │
                                          │ 数传 MAVLink（UDP）      │
                                          └─────────────────────────┘
```

三台设备各有一个固定 IP，互相能 `ping` 通，任务和状态就能传起来：

| 设备 | 固定 IP | 接入方式 |
|------|---------|----------|
| 中枢地面站 | `192.168.1.100` | 有线到交换机（推荐）或 5GHz |
| 地面机器人 SpiderPi Pro | `192.168.1.101` | 5GHz Wi-Fi |
| Minihomer 基站 | `192.168.1.123` | 有线到交换机 |
| 无人机图传摄像头 | `192.168.1.10` | 经 Minihomer 桥接 |

> 如果家里/场地只有普通路由器，没有 VLAN，也先照这个 IP 表在路由器 DHCP 里做
> MAC 静态绑定即可，不必一开始就上 AC/AP。

## 2. 先跑通协议，再配设备

新手按下面顺序做，**第 1、2 步是重点**：

### 第 1 步：读通信协议规范

打开 [通信协议规范.md](通信协议规范.md)，记住三句话：

1. 无人机 → 中枢：`MAVLink/UDP` 传状态，`RTSP/TCP` 传画面；
2. 中枢 → 机器人：`HTTP + JSON/TCP` 下发任务，端口 `5000`；
3. 机器人 → 中枢：`HTTP + JSON/TCP` 回传状态，端口 `5000`。

### 第 2 步：按端口表核对

最小端口只有这几个，其余按需：

| 端口 | 协议 | 用途 |
|------|------|------|
| 14550 | UDP | pymavlink 读无人机 MAVLink |
| 8080 | UDP | QGC 地面站 |
| 554 | TCP | RTSP 无人机画面 |
| 5000 | TCP | 机器人任务/状态服务 |
| 20001 | TCP | 中枢统一仪表盘 |

完整表见 [通信协议规范.md](通信协议规范.md) 第 2 节和
[../端口清单.md](../端口清单.md)。

### 第 3 步：三台设备接入同一网络

1. 地面站按 [../GroundStation/开始配置.md](../GroundStation/开始配置.md) 装好环境，
   Windows 网卡设为自动获取或固定 `192.168.1.100`；
2. 机器人按 [../GroundRobot/开始配置.md](../GroundRobot/开始配置.md) 第 7 节切成
   STA 局域网模式，连 `AGCS-5G`；
3. Minihomer 基站按 [../Dron/开始配置.md](../Dron/开始配置.md) 第 7 节配对，并把
   基站接到交换机。

### 第 4 步：按需配置无线设备

- H3C 设备 → [H3C无线网络配置.md](H3C无线网络配置.md)
- 华为设备 → [华为无线网络配置.md](华为无线网络配置.md)

## 3. 快速验证

```bat
:: 1. 三方互通
ping 192.168.1.100
ping 192.168.1.101
ping 192.168.1.123

:: 2. 机器人状态
curl http://192.168.1.101:5000/status

:: 3. 下发任务
curl -X POST http://192.168.1.101:5000/task ^
  -H "Content-Type: application/json" ^
  -d "{\"task_id\":\"T999\",\"target\":{\"x\":0.0,\"y\":0.0}}"
```

```bat
:: 4. 读无人机 MAVLink（脚本按 GroundStation/开始配置.md 配置后）
python D:\yolo\scripts\read_drone.py
```

打开中枢仪表盘：`http://192.168.1.100:20001`，应能看到无人机、机器人、模型
三类信息。

## 4. 新手常见坑

| 坑 | 说明 |
|----|------|
| 端口 5000 有两个 | 机器人服务是 TCP 5000；视频转发是 UDP 5000 |
| QGC 和 pymavlink 抢端口 | QGC 用 8080，pymavlink 用 14550，不能相同 |
| 地面站 IP 有两个口径 | 本方案统一为 `192.168.1.100`，`192.168.1.123` 给 Minihomer 基站 |
| 机器人还是直连模式 | 必须先切成 STA 局域网模式，否则中枢访问不到 |
| 先钻网络配置 | 先跑通 [通信协议规范.md](通信协议规范.md)，网络配置按需再做 |
