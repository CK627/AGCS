# 网络互联与协议负责人（Internet）学习与开发路线

> 你负责"网络互联 + 通信协议规范"。**第一优先不是配华为/H3C 设备，而是先把
> 无人机、地面机器人和中枢之间的通信协议与端口规范定下来、跑通。**
>
> 团队三阶段主线：
>
> 第一阶段「从人工到自动的跨越」→ 第二阶段「从单机到协同的进化」→
> 第三阶段「从可用到可靠的蜕变」
>
> 文档入口：
>
> - 新手先看：[开始配置.md](开始配置.md)，一张拓扑图看懂全局；
> - 第一优先：[通信协议规范.md](通信协议规范.md)，无人机/机器人/中枢怎么说话；
> - 网络配置：[H3C无线网络配置.md](H3C无线网络配置.md)、
>   [华为无线网络配置.md](华为无线网络配置.md)，按现场设备二选一。

## 2. 整体路线图：先协议，后建网

```text
第0步 认识三台设备与拓扑 ──▶ 模块1 通信协议规范（第一优先）
   │                                     │
   ▼                                     ▼
模块5 全链路验收 ◀── 模块4 转发与安全 ◀── 模块3 设备入网与互通
                                            │
                               模块2 华为/H3C 无线网配置（按需）
```

白搭；协议通了，网络只要按现场设备选一种配置即可。

## 5. 阶段合并

### 5.1 第一阶段：提出网络互联方案

1. 盘点无人机、地面机器人、中枢三类设备的网络接口与协议端口
2. 画出拓扑图，明确三句话：无人机→中枢走 MAVLink/RTSP，中枢→机器人走 HTTP JSON
3. 和谢啸确认地面站 IP/防火墙，和马晨轩确认机器人 STA 模式，和朱杨杰确认
   数传/图传地址

**验收**：能对着拓扑图讲清每个数据的源、目的、协议、端口。

### 5.2 第二阶段：先打通通信协议，再配无线网络

1. 先把 [通信协议规范.md](通信协议规范.md) 的端口表和消息格式定死
2. 跑通地面站 → 机器人任务下发与状态回传
3. 跑通无人机 → 地面站 MAVLink 数传和 RTSP 图传
4. 按现场设备选择 H3C 或华为，完成 SSID、VLAN、DHCP 静态绑定

**验收**：三方互通；地面站下发任务机器人返回 `accepted`；pymavlink 能读到位姿；
仪表盘能同时看到无人机、机器人、模型信息。

### 5.3 第三阶段：转发、安全与监控

1. 需要跨网段/公网调试时，按最小权限做端口转发或 VPN
2. 监控丢包、延迟、AP 信号和 DHCP 分配情况
3. 配合全体完成 README 4.5 全流程计时验收

**验收**：本地局域网全流程达标；跨网段只做受控调试，不把控制端口暴露公网。
