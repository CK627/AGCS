# 地面站开始配置（Windows 方案）

> 目标：机械革命笔记本（RTX 5060 8G / 32G 内存 / 1TB 固态）**直接用 Windows
> 作为地面站**，跑 YOLO + 无人机通信 + 机器人任务下发，不再安装 Ubuntu / ROS。
>
> 决策依据（官方）：
> - ROS 1 Noetic 官方只支持 Ubuntu 20.04，**不支持 Windows**；
> - NVIDIA 驱动在 Windows 上一键安装，无内核 / open 内核模块的烦恼；
> - QGC、pymavlink、RTSP、Flask 全部跨平台，无人机/机器人的核心链路不依赖 ROS；
> - 地面机器人 SpiderPi Pro 自身是树莓派 Linux，地面站只通过 HTTP/SSH 与它通信，
>   与地面站系统无关。
>
> 代价：放弃 ROS 1（MAVROS → pymavlink），没有 roscore/rostopic，调度改用
> MAVLink + HTTP。各文档里涉及 ROS 的命令都已按此方案改写。

## 1. 为什么用 Windows

| 对比项 | Windows | Ubuntu（旧方案） |
|--------|---------|-------------------|
| RTX 5060 驱动 | NVIDIA 官网/GeForce 一键安装 | 需要 570+ **open 内核模块**，还受内核版本影响 |
| YOLO（torch cu128） | 官方支持，pip 直接装 | 同样支持，但环境要先折腾 |
| 无人机地面站 QGC | Windows 原生 | 需要额外安装 |
| MAVLink 读取 | pymavlink（pip 装） | 需要 ROS + MAVROS |
| 机器人通信 | HTTP / SSH（与平台无关） | 同上 |
| ROS 生态 | 不支持 ROS 1 | 支持 ROS Noetic（但整套环境重） |

## 2. 硬件与磁盘规划

本机：**机械革命笔记本，RTX 5060 8G 显存 / 32G 内存 / 1TB 固态，Windows 10/11
64 位**。

建议统一目录（数据集、模型、脚本都放一起，便于同步和备份）：

```text
D:\yolo\
├── datasets\    # 数据集（图片、labels、data.yaml）
├── runs\        # 训练结果（best.pt、results.png）
├── weights\     # 模型权重
└── scripts\     # 推理/训练/拉流脚本
```

> 8G 显存 + 32G 内存对 YOLOv8n/s 训练和实时推理完全够用；1TB 固态建议给
> 数据集和模型预留 200GB 以上空间。

## 3. 安装 NVIDIA 驱动（Windows 下最简单的一步）

1. 更新 Windows（设置 → Windows 更新），让系统装上最新驱动；
2. 装 NVIDIA App（原 GeForce Experience）或直接到
   [https://www.nvidia.com/Download](https://www.nvidia.com/Download) 选
   **RTX 5060 Laptop GPU + Windows 11** 下载驱动安装；
3. 重启后验证（PowerShell 或 CMD）：

```bat
nvidia-smi
```

能看到 `NVIDIA GeForce RTX 5060 Laptop GPU`、显存 8192MiB、驱动版本 ≥570
即成功。

> 如果在 CMD 里提示"不是内部或外部命令"，说明驱动没装好或 PATH 没加，重装
> 驱动即可（nvidia-smi 位于 `C:\Windows\System32\nvidia-smi.exe`）。

## 4. 安装 Python 与 YOLO 环境（CUDA 版）

1. 到 [python.org](https://www.python.org/downloads/) 下载 **Python 3.10 或
   3.11**，安装时勾选 **Add python.exe to PATH**；
2. 打开 CMD/PowerShell，安装依赖：

```bat
python -m pip install --upgrade pip
python -m pip install ultralytics opencv-python
:: RTX 5060 是 Blackwell（sm_120），必须装 CUDA 12.8+ 的 torch（2.7+）
python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
```

> 注意：**不要用默认源装 torch**（默认是 CPU 版或旧 CUDA 版）。RTX 5060 只有
> `+cu128` 起的 torch 带对应 kernel，装错会报 `sm_120 not compatible` /
> `no kernel image is available`。

验证：

```bat
python -c "import torch; print(torch.__version__, 'CUDA:', torch.cuda.is_available())"
python -c "import ultralytics, cv2; print(ultralytics.__version__, cv2.__version__)"
```

期望 `CUDA: True` 且 torch 版本形如 `2.7.0+cu128`。跑一次 GPU 示例推理：

```bat
python -c "from ultralytics import YOLO; m=YOLO('yolov8n.pt'); m.predict('https://ultralytics.com/images/bus.jpg', save=True, device=0)"
```

性能验收：

```bat
yolo benchmark model=yolov8n.pt device=0
```

RTX 5060 上 yolov8n 通常 100+ FPS，**≥60 FPS 即为通过**。

## 5. 安装 QGroundControl（无人机地面站）

QGC 是 Windows 原生软件，去 [https://qgroundcontrol.com](https://qgroundcontrol.com/)
下载 Windows 安装包安装。

|--------|-----|
| 笔记本以太网静态 IP | 192.168.1.123 |
| QGC 连接类型 | UDP |

```text
rtsp://192.168.1.10:554/user=admin&password=&channel=1&stream=1.sdp?
```

上完全一致）。

## 6. 安装 pymavlink（替代 MAVROS，读无人机数据）

MAVROS 是 ROS 专属，Windows 用官方 MAVLink 的 Python 库 **pymavlink** 替代，
直接读飞控的位置/姿态/电量：

```bat
python -m pip install pymavlink
```

最小读取脚本 `D:\yolo\scripts\read_drone.py`：

```python
from pymavlink import mavutil

# 数传默认端口：QGC 用 8080，pymavlink 建议监听 14550（可在数传端添加目标）
conn = mavutil.mavlink_connection('udpin:0.0.0.0:14550')
print('等待飞控心跳...')
conn.wait_heartbeat(timeout=15)
print('已连接，目标系统 %d' % conn.target_system)

while True:
    msg = conn.recv_match(blocking=True, timeout=1.0)
    if msg is None:
        continue
    if msg.get_type() == 'LOCAL_POSITION_NED':
        # NED（北-东-下）→ ENU（东-北-上）：东=x的y，北=x的x，上=-z
        print('position ENU(m): x=%.2f y=%.2f z=%.2f' % (msg.y, msg.x, -msg.z))
    elif msg.get_type() == 'GLOBAL_POSITION_INT':
        print('GPS: lat=%.7f lon=%.7f alt=%.2f m' %
              (msg.lat / 1e7, msg.lon / 1e7, msg.alt / 1000.0))
    elif msg.get_type() == 'HEARTBEAT':
        armed = bool(msg.base_mode & mavutil.mavlink.MAV_MODE_FLAG_SAFETY_ARMED)
        print('mode=%s armed=%s' % (mavutil.mode_string_v10(msg), armed))
    elif msg.get_type() == 'SYS_STATUS':
        print('battery: %.2f V %d%%' % (msg.voltage_battery / 1000.0,
                                        msg.battery_remaining))
```

> 端口说明：QGC 监听 8080，pymavlink 监听 14550（MAVLink 默认地面站端口）。
> 若数传只把数据发往一个目标，需要在数传/飞控端把地面站 IP+14550 加为额外
> 目标，或让 pymavlink 与 QGC 共用串口数据。联调时以实际数传配置为准。

教学文档：[Dron/教学/MAVLink与MAVROS.md](../Dron/教学/MAVLink与MAVROS.md)
（已改为 pymavlink 版本）。

## 8. 防火墙与网络

地面站是 Windows，首次运行 QGC / pymavlink / 仪表盘时防火墙弹窗要**允许专用
网络访问**。需要放行的端口：

| 端口 | 协议 | 用途 |
|------|------|------|
| 8080 | UDP | QGC 数传监听 |
| 14550 | UDP | pymavlink 数传监听 |
| 20001 / 5000 / 8000 | TCP | 仪表盘 / 机器人任务 / YOLO API（内网） |

固定 IP 在路由器 DHCP 里按 MAC 绑定（地面站 192.168.1.100、机器人
192.168.1.101、无人机图传 192.168.1.10）。网络部门跨网段端口转发见
[YOLO教学与空地协同.md](../YOLO教学与空地协同.md) 7.8。

## 11. 常见问题

| 现象 | 原因 / 排查 |
|------|-------------|
| torch 报 `sm_120 not compatible` / `no kernel image` | torch 不是 cu128 版，重装：`python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128` |
| `CUDA: False` | 驱动没装好；`nvidia-smi` 看显卡是否出现 |
| `nvidia-smi` 不是内部命令 | 驱动未安装或 PATH 问题，重装驱动 |
| QGC 连不上 | 静态 IP 192.168.1.123；防火墙放行；`SER_TEL1_BAUD=57600` |
| pymavlink 收不到心跳 | 端口 14550 没开/数传目标没加；先让 QGC 能连上再排查 |
| 机器人同步脚本 .sh 跑不了 | Windows 用 Git Bash / WSL 运行，或 WinSCP 手动传 |
| 防火墙弹窗挡了服务 | 允许"专用网络"访问；内网联调不要选公用网络 |
