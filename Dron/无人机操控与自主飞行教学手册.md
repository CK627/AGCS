# 无人机操控与自主飞行教学手册（电脑互通 + Python 方案）

> 本手册把"操控无人机"和"用电脑控制/看数据"串成一条可执行的学习链，
> 配套代码在 [Dron/Code/](Code/README.md)，已有基础文档见
> [Dron/开始配置.md](开始配置.md) 和 [Dron/教学/](教学/README.md)。

## 0. 规划：四个阶段

| 阶段 | 主题 | 做什么 | 用到的工具/代码 | 安全级别 |
|------|------|--------|------------------|----------|
| 阶段 0 | 操控入门 | 遥控飞行、定点悬停、QGC 看状态 | 遥控器 + QGC | 高（有人肉监控） |
| 阶段 1 | 电脑互通 | 电脑连上无人机（数传/USB），Python 建立 MAVLink 连接 | `connect.py` | 只读，安全 |
| 阶段 2 | 数据查看与可视化 | 实时打印姿态/GPS/电量，画曲线、存日志 | `view_data.py` / `plot_data.py` | 只读，安全 |
| 阶段 3 | 自主飞行 | QGC 航线 → Python 上传任务并启动 | `mission.py` | **高危，必须预检** |

原则：**阶段 0/1/2 全部只读，不碰油门；阶段 3 才涉及飞行**，且默认只上传任务
不启动，加 `--start` 并人工确认后才会飞。

> **真机没到怎么办**：阶段 1/2 全部可以用 `sim_drone.py` 假无人机模拟器练习
> （见 2.4 节），互通代码在真机上只需改连接配置，其他不变。

## 2. 阶段 1：无人机与电脑互通

### 2.1 三条通路

```text
通路A（无线·数传）: 无人机 ──Minihomer──▶ 笔记本 UDP（QGC 用 8080，pymavlink 用 14550）
通路B（有线·USB） : 飞控 ──Type-C──▶ 笔记本 串口 57600
通路C（程序·MAVLink）: 上面的数据本身就是 MAVLink 消息，Python 直接读
```

QGC 用的是通路 A/B；我们自己写 Python 也用通路 A/B，只是把 QGC 换成代码。

### 2.2 两种电脑端工具

| 工具 | 类型 | 用途 |
|------|------|------|
| QGroundControl | 图形界面 | 校准、看状态、规划航线、人工监控 |
| pymavlink（Python） | 编程接口 | 自己写程序读数据、控制飞行 |
| MAVProxy（可选） | 命令行 | 交互式查看：`mavproxy.py --master=udpin:0.0.0.0:14550` |

### 2.3 连接配置（改 `Code/drone_config.py`）

| 连接方式 | 配置字符串 | 说明 |
|----------|------------|------|
| 数传 UDP（pymavlink） | `udpin:0.0.0.0:14550` | QGC 用 8080；pymavlink 用 14550，需在数传端把"地面站 IP + 14550"加为发送目标 |
| USB 直连（Windows） | `serial:COM3,57600` | 设备管理器查 COM 号 |
| USB 直连（Linux） | `serial:/dev/ttyUSB0,57600` | 波特率 57600 |
| SITL 仿真（练习） | `udpout:127.0.0.1:14550` | 本地仿真调试 |

> 端口分工：QGC 监听 8080，pymavlink 监听 14550，两者互不抢占。

### 2.4 没有真机怎么练（重要）

先学理论再看代码：[Python与无人机互通-库函数详解.md](教学/Python与无人机互通-库函数详解.md)
（每个 pymavlink 函数对应无人机上的什么）。

然后开两个终端：

```bash
# 终端1：假无人机模拟器（扮演飞控，向 14550 广播数据）
python3 Code/sim_drone.py

# 终端2：接收端任选
python3 Code/read_drone.py
python3 Code/view_data.py
```

真机到货后：关掉模拟器，把 `drone_config.py` 改成数传/串口连接，
**接收端代码一行都不用改**。

> 后端输出训练（测试数据 → JSON）：见 [Code/backend_exercise.md](Code/backend_exercise.md)；
> 网页部分由队友编写，无人机侧不用学 web。

## 3. 阶段 2：在电脑上查看数据（Python）

### 3.1 安装环境

```bash
python -m pip install pymavlink matplotlib pyserial
```

### 3.2 常用数据（MAVLink 消息 → 字段 → 单位）

| 消息 | 字段 | 单位换算 |
|------|------|----------|
| `ATTITUDE` | roll / pitch / yaw | 弧度 → 角度 `math.degrees()` |
| `GLOBAL_POSITION_INT` | lat / lon / relative_alt | 经纬度 ÷1e7；高度 mm → m |
| `GPS_RAW_INT` | fix_type / satellites_visible / eph | fix≥3 定位；星数；eph 为厘米 |
| `BATTERY_STATUS` | voltage_battery / battery_remaining | mV → V；剩余百分比 |
| `VFR_HUD` | heading / groundspeed / climb / throttle | 度 / m/s / m/s / % |
| `HEARTBEAT` | base_mode / custom_mode | 解锁位 `base_mode & 128` |

### 3.3 三个代码入口

```bash
cd Dron/Code
python3 read_drone.py     # 最小读取：先跑通
python3 view_data.py      # 实时打印姿态/GPS/电量/模式
python3 plot_data.py --live --seconds 60   # 实时曲线
python3 plot_data.py --tlog 日志文件.tlog   # 回放飞行日志
```

每个文件都有配套教学文档，先读再跑。

## 4. 阶段 3：自主飞行

### 4.1 安全前提（不满足不要飞）

- GPS fix≥3、卫星数≥10（官方建议室外 ≥15）
- 电池电量充足（≥50% 建议）
- 场地开阔、远离人群，有人盯着，遥控器在手
- 解锁用**遥控器 5 通道**，本套代码**不会自动解锁**
- 随时准备 6 通道急停、7 通道返航

### 4.2 三步路线（难度递增）

1. **QGC 手工航线**：在地图点几个航点 → 上传 → 8 通道拨到任务模式 → 解锁。
   先让"人"验证航线安全。
2. **Python 上传任务**（`mission.py`，默认只上传不飞）：程序把航点打包成
   MAVLink 任务，上传到飞控，打印预览给你确认。
3. **Python 启动任务**（`mission.py --start`）：预检通过后切 AUTO.MISSION、
   发 MISSION_START，用遥控器解锁起飞，程序只做监控。

### 4.3 任务上传协议（教学理解）

```text
我们 ──mission_count(数量)──▶ 飞控
飞控 ──MISSION_REQUEST_INT(seq)──▶ 我们   （每个航点问一次）
我们 ──mission_item_int(seq,坐标,高度)──▶ 飞控
飞控 ──MISSION_ACK(结果)──▶ 我们
```

### 4.4 进阶预告：OFFBOARD 模式（暂不开放）

OFFBOARD 是"机载电脑直接发速度/位置指令"的模式，是真正意义上的自主飞行，
但**写错一个数据就可能炸机**。当前阶段只要求理解概念，代码框架后续再给。

## 5. 报错解析与解决方案总表

| 现象 | 原因 | 解决 |
|------|------|------|
| `No heartbeat` / 连接超时 | 通路没通：IP/端口/波特率错 | 先 QGC 确认能连；再试 `connect.py` |
| 与 QGC 抢端口 | 两个程序监听同一 UDP 端口 | QGC 用 8080、pymavlink 用 14550，不要重复 |
| 串口权限不足 | Linux `/dev/ttyUSB0` | `sudo usermod -aG dialout $USER` 后重登 |
| 数据一直不变 | 没请求数据流或消息频率低 | 摇动无人机看是否更新；等 2 秒 |
| 经纬度为 0 | GPS 未定位 | 室外等定位，fix≥3 |
| 电量显示 -1 | 电池消息字段未就绪 | 用 `voltage_battery` 看电压 |
| `MISSION_REQUEST` 超时 | 上传协议顺序错 | 按 4.3 顺序：count → 逐条应答 → ack |
| 任务上传成功但不飞 | 没切任务模式/没解锁 | 8 通道拨任务模式；5 通道解锁 |
