## 4. 电池与充电

电池是 4S1P 锂聚合物（LiPo），单片电芯电压 4.2V。

### 4.1 充电

1. 使用**不低于 30W** 的快充电源适配器连接充电器
2. 接好电池**平衡头**和 **XT60** 接口
3. 充电器选择电池类型 **LiPo**，充电电流 **3A**，开始充电

警告：

- 严禁电池过放、长时间放在车内
- 充电器只适用锂离子/锂聚合物电池
- 任何时间只能连接 1 个电池平衡口

### 4.2 维护与电压检查

- 存放：干燥阴凉处，建议防火袋/防爆箱；满电久放会老化，**最佳存放电压约
  3.85V/片**
- 飞行前：用配套平衡头转接线 + BB响测电压，**总电压 15.2~16.8V 正常**

## 5. 开机与关机

1. 电池接口朝内，沿滑轨平稳推入，确认 XT60 接紧，划下电池尾端锁扣
2. 开机：先**短按**电源按键（>150ms），再**长按 3 秒**，电源指示灯全部点亮
3. 关机：同样先短按再长按 3 秒

指示灯含义：

| 状态 | 含义 |
|------|------|
| 红蓝交替闪烁 | 正在初始化传感器，**请保持飞控水平** |
| 蓝色常亮 | 已解锁（Armed），但无 GPS 锁定 |
| 绿色常亮 | 飞机已解锁，准备起飞 |
| 外围 6 个灯逐个熄灭，最后红灯闪烁 | 电量用尽，尽快降落 |

## 6. 遥控器

### 6.1 通道默认设置（出厂已配置）

| 通道 | 开关 | 作用 |
|------|------|------|
| 5 通道 | 上→下 | 解锁开关 |
| 6 通道 | 上→下 | 急停（一键锁桨） |
| 7 通道 | 上→下 | 返航模式 |
| 8 通道 | 上/中/下 | 定点模式 / 降落模式 / 任务模式 |

### 6.2 注意事项

- 使用前把天线**斜角向上**打开，飞行中不要手握天线
- 混控开关放**中间**（无混控）
- 微调键：按一下 1 微秒变化，长按 4 微秒
- 遥控器发出"哔哔"声且指示灯闪烁 = 电量不足
- 开机前确保所有开关拨到**最上方**，避免解锁状态下开机

## 7. 数传连接（关键步骤）

1. 数传**基站端**通过网线连接笔记本
2. 笔记本设置**静态 IP：192.168.1.123**（打开更改适配器选项 → 以太网 → IPv4）
3. 给无人机通电，同时打开数传基站端电源
4. 打开 QGC，进入通讯连接界面，**添加新连接**：

| 配置项 | 值 |
|--------|-----|
| 自定义名称 | 任意，如 `drone` |
| 类型 | UDP |
| 监听端口 | 8080 |

5. 点击连接，QGC 出现无人机状态即为成功

常见问题：

| 现象 | 排查 |
|------|------|
| 数传无反应 | 是否配对完成；与飞控相连端口的目的 IP 是否等于电脑静态 IP（192.168.1.123）；防火墙是否关闭 |
| 仍无反应 | 检查波特率参数 `SER_TEL1_BAUD` 是否为 57600 |

## 8. QGC 地面站与校准

### 8.1 USB 直连（校准用）

用 Type-C 数据线连接飞控与笔记本，QGC 添加串口连接：选择电脑识别的 COM 口，
波特率 **57600**，然后连接。传感器校准需进入 QGC **开发者模式**。

### 8.2 传感器校准

按顺序校准，均在"传感器"界面操作：

1. **罗盘**：按提示摆放无人机，等待旋转标志出现后旋转，直到提示框变绿，依次校准所有面
2. **陀螺仪**：水平摆放即可，校准中不可移动
3. **加速度计**：按提示摆放并保持静止，直到变绿，依次校准所有面
4. **地平线**：水平摆放，保持静止直至完成

### 8.3 电池电压校准

1. 用测电仪测出实际电池电压
2. 进入电源界面，填写：电池芯数 `4`、空电电压 `3.60`、满电电压 `4.20`
3. 点击计算，填写实测电压，再次计算
4. 校准后确认电量显示正常

### 8.4 遥控器校准

进入遥控器界面，选择**与遥控器一致的摇杆模式**，点击校准，按提示拨动摇杆。

### 8.5 参数保存与加载

重置参数前**务必先保存**：QGC 开发者模式 → 参数 → 工具 → 保存到文件；
恢复时选择加载文件。

## 9. 图像检查（图传）

无人机通过数传连接地面站后，图像默认自动出现。如果没有画面：

1. 地面站选择【常规】→ Source 选择 **RTSP Video Stream**
2. RTSP URL 填写：

```
rtsp://192.168.1.10:554/user=admin&password=&channel=1&stream=1.sdp?
```

3. 返回主页即可看到画面；录像/拍照按钮在画面工具栏，文件保存在本地相应目录

## 10. 飞行前检查（每次必做）

1. 外观：外壳、机架、电机座、GPS、数传天线无松动
2. 电池：电压 15.2~16.8V，安装到位、锁扣扣好
3. QGC 概况检查：无人机状态**绿色**；无法解锁看"消息打印"
4. 室外飞行：GPS 卫星数 **≥15**
5. 电量满足飞行条件；旋转无人机，仪表盘姿态应与实际对应
6. 建议全程使用**定点模式**；室内光线充足，光线太暗影响定点效果

> 新手安全提示：首次试飞先**拆下螺旋桨**做状态检查；场地开阔、远离人群，
> 可使用附带的 30m 安全绳；紧急情况用 6 通道急停。

## 11. 首次飞行步骤

1. 室外开阔场地，装上螺旋桨（注意正反桨方向）
2. 开机，等待 GPS 锁定（卫星数 ≥15），QGC 概况全绿
3. 遥控器 8 通道拨到**上（定点）**，5 通道解锁
4. 轻推油门，无人机起飞并稳定悬停（摇杆回中即保持不动）
5. 练习前后/左右/旋转，最后缓慢收油门降落，自动上锁

## 13. 常见问题

**Q：数传连不上？**

按第 7 节排查：配对 → 静态 IP 192.168.1.123 → 关闭防火墙 → 检查
`SER_TEL1_BAUD=57600`。

**Q：QGC 没有图像？**

确认数传已连接，再按第 9 节配置 RTSP Video Stream 与 URL。

**Q：无法解锁？**

看 QGC"消息打印"的具体报错；检查飞行模式、GPS 信号、电池电量；确认遥控器
开关在最上方再开机。

**Q：校准一直失败？**

罗盘/加速度计必须按提示摆放并保持静止；陀螺仪校准中不可移动；先确认用的是
USB 直连且波特率 57600。

**Q：指示灯红蓝交替很久？**

正在初始化传感器，保持飞机水平静止等待；若长时间不恢复，检查传感器状态。
