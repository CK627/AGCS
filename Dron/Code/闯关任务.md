# 无人机 Python 闯关任务（从最简单到完整）

把学习当成游戏闯关：一关只做一件事，跑通了再进下一关。
所有关卡的数据都从 `test_data/` 读取，不需要无人机，也不需要模拟器。

先读 [黑话对照表.md](黑话对照表.md)，把专业词换成生活比喻，再开始闯关。

## 关卡地图

```text
第1关 门牌号 ─▶ 第2关 报平安 ─▶ 第3关 第一张纸条 ─▶ 第4关 读全纸条
                                                          │
第10关 综合实战 ◀── 第9关 自己造纸条 ◀── 第8关 任务清单 ◀── 第7关 画曲线 ◀── 第6关 出货单 ◀── 第5关 汇率换算
```

## 第 1 关：认识门牌号

目标：知道电脑要"去哪等信"。

```bash
python3 -c "from drone_config import CONNECTION, TIMEOUT; print(CONNECTION, TIMEOUT)"
```

验收：能说出 `udpin:0.0.0.0:14550` 里的 14550 是什么（听信的端口）。

教学：[drone_config.md](drone_config.md)

## 第 2 关：收到"报平安"

目标：确认能和无人机（或日志）对上话。

```bash
python3 read_drone.py --tlog test_data/flight_sample.tlog
```

验收：输出里能看到 `mode=LOITER`，说明收到心跳了。

教学：[connect.md](connect.md)、[read_drone.md](read_drone.md)

## 第 3 关：取第一张"纸条"

目标：读懂一种消息（姿态），并说出它来自无人机的哪个部件。

```bash
python3 read_drone.py --tlog test_data/flight_sample.tlog
```

验收：能指着 `yaw=...` 说出"这是转向角度，来自 IMU，原本是弧度，这里换成了度"。

教学：[read_drone.md](read_drone.md) 的"单位换算"表

## 第 4 关：把所有纸条读全

目标：一次拿到状态、姿态、位置、GPS、电池、飞行、局部位置。

```bash
python3 all_data.py --tlog test_data/flight_sample.tlog
```

验收：输出的每一段你都知道对应无人机什么。

教学：[all_data.md](all_data.md)

## 第 5 关：汇率换算（单位换算）

目标：自己动手把原始值换算成好读的数值。

任务：读 `test_data/telemetry_sample.csv`，把 `volt` 换算成"伏"显示，把
`roll_deg` 换成弧度、再换回度，验证结果一致。

验收：能写出 `mm_to_m(x)` 函数，并说出为什么飞控用毫米。

教学：[view_data.md](view_data.md) 的"单位换算表"

## 第 6 关：整理成出货单（后端输出）

目标：把读到的数据按约定格式输出成 JSON 文件，供网页（队友）使用。

```bash
python3 backend_exercise.py                       # 读 telemetry_sample.csv
python3 backend_exercise.py --csv test_data/telemetry_flight.csv
```

验收：补完三个 TODO，生成 `telemetry.json` 和 `history.jsonl`，并与
`test_data/history_sample.jsonl` 对照。

教学：[backend_exercise.md](backend_exercise.md)

## 第 7 关：画成"心电图"

目标：把数据画成曲线，看到变化趋势。

```bash
python3 plot_data.py --tlog test_data/flight_sample.tlog
```

验收：能看到姿态、高度、电池三张图；说出为什么离线也能画（读的是录像带）。

教学：[plot_data.md](plot_data.md)

## 第 8 关：给无人机一张"路线任务清单"

目标：理解任务 = 起飞 + 航点 + 返航，并会离线预览。

```bash
python3 mission.py --waypoints "31.2305,121.4738,10;31.2306,121.4739,10" --preview
```

验收：能说出 `#0/#1/#3` 分别是什么动作，并对照 `test_data/mission_sample.json`。

教学：[mission.md](mission.md)

## 第 9 关：自己造"纸条"

目标：写一个假无人机，向电脑发数据，理解发送和接收是一对。

```bash
# 终端1
python3 sim_drone.py
# 终端2
python3 all_data.py
```

验收：终端2 能实时打印数据；改模拟器里的 yaw 值，终端2 跟着变。

教学：[sim_drone.md](sim_drone.md)

## 第 10 关：综合实战

目标：串起完整流程——读数据、整理成 JSON、回放/实时、任务预览。

任务清单：

1. `all_data.py --tlog` 读全参数
2. `backend_exercise.py` 输出 JSON
3. `plot_data.py --tlog` 回放曲线
4. `mission.py --preview` 预览任务
5. 用 `sim_drone.py` + `all_data.py` 做一次在线联调

验收：能不看文档，完整跑通上面 5 步，并解释每一步的数据来源。

## 通关后的下一步

把 `backend_exercise.py` 的"读 CSV"换成"读无人机"（参考 `all_data.py`），
你的后端就完成了；网页部分由队友按 `telemetry.json` / `history.jsonl` 的
约定去写。
