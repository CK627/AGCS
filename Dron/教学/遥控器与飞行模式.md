# 遥控器与飞行模式 教学文档

## 1. 遥控器 QE-2 是什么

8 通道遥控器。**通道（Channel）**就是"一路控制信号"：

| 通道 | 默认用途 |
|------|----------|
| CH1-CH4 | 摇杆：横滚、升降、油门、方向 |
| CH5 | 解锁开关（上→下解锁） |
| CH6 | 急停开关（一键锁桨） |
| CH7 | 返航开关 |
| CH8 | 飞行模式：上=定点 / 中=降落 / 下=任务 |

出厂已配置好，本机**不需要重新设置通道**，但要知道每个开关干嘛，否则误拨
会出事（比如飞行中拨到急停）。

## 2. 混控开关

遥控器侧面的混控开关有三档：

- 上方：三角翼混控模式
- **中间：无混控（本机使用）**
- 下方：固定翼混控模式

多旋翼必须放在中间档。

## 3. 飞行模式

| 模式 | 难度 | 行为 |
|------|------|------|
| 定点模式 | 易 | 摇杆回中即稳定悬停（室内外常用，**建议新手全程使用**） |
| 定高模式 | 易 | 保持当前高度，会随风漂移 |
| 自稳模式 | 难 | 需手动控油门保持高度，漂移明显 |
| 起飞模式 | 自动 | 自动起飞到设定高度悬停 |
| 降落模式 | 自动 | 自动降落并上锁 |
| 任务模式 | 自动 | 按上传的航线自主飞行 |
| 返航模式 | 自动 | 返回起飞点悬停或降落（需 GPS） |

理解方式：**自动模式（起飞/降落/任务/返航）不需要摇杆**，遥控器只是"开始
执行"的开关；手动模式（定点/定高/自稳）需要摇杆实时控制。

## 4. 解锁与急停

本机用开关解锁，不是传统的摇杆"内八"：

- **解锁**：5 通道从上拨到下。定点模式下一键解锁/上锁；自稳模式需油门最低位
- **急停**：6 通道，低空失控/炸机后电机不停时使用，一键锁桨

> 急停一旦使用飞机会直接掉下来，**一般不建议使用**，只在保护人身安全时用。

## 5. 微调与正反

- 微调键：按一下 1 微秒变化，长按 4 微秒
- 方向/横滚/油门/升降各有正反开关，出厂已调好，不要乱动

## 6. 常见问题排查

| 现象 | 可能原因 | 排查/解决 |
|------|----------|-----------|
| 无法解锁 | 开关没在最上方开机 / 模式不对 / 有报错 | 检查 5 通道与 QGC 消息打印 |
| 飞行中突然切换模式 | 误碰 8 通道开关 | 起飞前确认开关位置，飞行中手不碰开关 |
| 遥控器哔哔报警 | 电量不足 | 充电；指示灯闪烁即电量低 |
| 方向/油门反了 | 正反开关被改 | 对照手册恢复出厂设置 |

## 7. 动手练习

1. 不开机状态下，拨动 5/6/7/8 通道，说出每个开关的作用
2. 定点模式悬停，练习"回中即停"的手感
3. 查 QGC 遥控器界面，摇动各摇杆，观察通道数值变化
