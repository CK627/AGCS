# 固件与参数 教学文档

## 1. 固件是什么

固件是烧录在飞控芯片里的软件，相当于"飞控的操作系统"。本机出厂固件是
**基于 PX4 v1.13.3 的定制固件**，也支持其他 PX4/ArduPilot 固件。

什么时候需要动固件？

- 官方发布更新、修复 Bug
- 需要特定功能（如 RTK、特殊传感器）
- 飞控变砖或参数混乱需要恢复

## 2. 通过 QGC 烧写固件

1. QGC → 固件界面
2. 用数据线连接飞控与电脑
3. 选择固件文件路径，点击打开
4. 等待烧写完成（有成功标志）

注意：烧写前**保存当前参数**（见下），烧写会重置配置。

## 3. 参数：飞控的"设置"

飞控有几百个参数，比如数传波特率 `SER_TEL1_BAUD=57600`。改参数前先学会
保存和加载：

- **保存**：QGC 开发者模式 → 参数 → 工具 → 保存到文件
- **加载**：工具 → 加载文件

> 重置全部参数前务必先保存一份，否则恢复出厂后要重新校准。

## 4. 三类校准

### 4.1 传感器校准（换环境/首次使用必做）

罗盘 → 陀螺仪 → 加速度计 → 地平线，按 QGC 提示摆放，保持静止直到变绿。

### 4.2 电池电压校准

让电量显示准确：填写芯数 `4`、空电 `3.60`、满电 `4.20`，再填入实测电压计算。

### 4.3 电调校准

按提示安装电池，点击电调校准，按机身按键供电，自动开始。

> 电调校准一般出厂已做好，乱校准可能把油门行程搞乱，新手非必要不做。

## 5. 固件编译环境（进阶）

想自己改 PX4 源码需要 Ubuntu 环境：

1. `git` 下载源码（prometheus_px4）
2. 切换分支、更新子模块（需科学上网）
3. 编译固件

这是第三阶段之后的事情，第一阶段只需会用 QGC 烧官方固件。

## 6. 常见问题排查

| 现象 | 可能原因 | 排查/解决 |
|------|----------|-----------|
| 烧写失败 | 固件文件不匹配/线材问题 | 用官方固件；换线；重试 |
| 烧完参数全没 | 未保存参数 | 下次先保存；本次重新校准 |
| 电量显示不准 | 未做电池电压校准 | 按 4.2 校准 |
| 传感器校准失败 | 未保持静止/摆放不对 | 严格按提示操作 |
| 电调行程乱 | 误校准电调 | 联系售后恢复出厂参数 |

## 7. 动手练习

1. 练习一次"参数保存 → 改动 → 加载"的完整流程
2. 在参数页搜索并解释 `SER_TEL1_BAUD`、`MAV_1_CONFIG` 的含义
3. 说出固件、参数、校准三者的关系（谁影响谁）
