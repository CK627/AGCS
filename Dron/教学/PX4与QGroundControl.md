# PX4 与 QGroundControl 教学文档

## 1. 三个概念先分清

| 概念 | 是什么 | 类比 |
|------|--------|------|
| **Pixhawk 6C 飞控** | 一块硬件电路板，无人机的"大脑" | 电脑主板 |
| **PX4 固件** | 跑在飞控上的开源飞行控制软件 | 操作系统 |
| **QGroundControl（QGC）** | 跑在电脑/手机上的地面站软件 | 控制台/仪表盘 |

F450 V6C 出厂固件是 **PX4 v1.13.3 定制版**，FMU 处理器为 STM32H743，
IO 处理器为 STM32F103。

三者配合：飞控负责"感知（传感器）→ 决策（控制算法）→ 输出（电机）"，
QGC 负责"看状态、做校准、规划航线、改参数"，两者通过 MAVLink 协议通信。

## 2. PX4 飞控在做什么

PX4 是一个运行循环，每一瞬间都在做：

```
读取传感器（IMU/气压计/GPS/光流）
  → 估算姿态与位置（卡尔曼滤波等算法）
  → 读取遥控器/任务指令
  → 计算每个电机的转速
  → 输出 PWM/CAN 信号驱动电机
```

关键点：飞控**自己不会飞**，它只是按照"期望姿态/位置"和"当前姿态/位置"
的差值去调电机。姿态估计算不准，飞行就不稳——这就是为什么要校准传感器。

## 3. QGC 能做什么

| QGC 界面 | 功能 |
|----------|------|
| 通讯连接 | 添加数传（UDP 8080）或 USB（串口 57600）连接 |
| 概况 | 查看无人机状态、电池、GPS、是否解锁，全绿=正常 |
| 传感器 | 罗盘/陀螺仪/加速度计/地平线校准 |
| 电源 | 电池电压校准 |
| 遥控器 | 摇杆模式选择与校准 |
| 参数 | 查看/修改飞控参数，保存/加载参数文件 |
| 固件 | 烧写/更新固件 |
| 规划 | 航点规划、任务上传 |
| 开发者模式 | 隐藏的校准/参数功能，校准前需开启 |

## 4. 连接方式

```text
数传（无线，飞行中用）: 无人机 ──Minihomer──▶ 笔记本(192.168.1.123) UDP 8080
USB  （有线，校准用） : 飞控 ──Type-C──▶ 笔记本，串口 57600
```

- 飞行中看状态、图传 → 用数传
- 校准、烧固件、改参数 → 用 USB 直连更稳

## 5. 常见问题排查

| 现象 | 可能原因 | 排查/解决 |
|------|----------|-----------|
| QGC 连不上 | 静态 IP 不对 / 防火墙 / 未配对 | 检查 192.168.1.123；关闭防火墙；重新配对 |
| 概况显示红色 | 传感器未校准或故障 | 进入传感器界面重新校准 |
| USB 连不上 | 波特率不对 / 驱动缺失 | 串口波特率选 57600；换 Type-C 数据线 |
| 固件烧写失败 | 固件文件不对 / 线材问题 | 按官方资料重新下载固件；换线重试 |

## 6. 动手练习

1. 分别用数传和 USB 连接 QGC，体会两种方式的应用场景
2. 打开"概况"页，说出每一项绿色/红色分别代表什么
3. 在参数页搜索 `SER_TEL1_BAUD`，理解它的含义（数传波特率）
