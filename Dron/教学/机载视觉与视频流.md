# 机载视觉与视频流 教学文档

## 1. 摄像头 IVG-G4

| 项目 | 值 |
|------|-----|
| 编码 | H.265+，双码流，AVI 格式 |
| 主码流 | 2560×1440@18fps / 2304×1296@20fps |
| 辅码流 | 800×448@25fps |
| 输出 | RTSP 网络流 |

理解：**主码流清晰、辅码流流畅**。检测算法用辅码流更快，存储/取证用主码流。

## 2. 视频流链路

```text
机载摄像头 → RTSP 地址 → 数传/网络 → 地面站拉流 → OpenCV/YOLO 处理
```

RTSP 地址（出厂默认）：

```
rtsp://192.168.1.10:554/user=admin&password=&channel=1&stream=1.sdp?
```

用 VLC 能打开 = 链路通。用 OpenCV 拉流：

```python
import cv2
cap = cv2.VideoCapture("rtsp://192.168.1.10:554/user=admin&password=&channel=1&stream=1.sdp?")
while True:
    ok, frame = cap.read()
    if ok:
        cv2.imshow('drone', frame)
    if cv2.waitKey(1) == 27:
        break
cap.release()
```

## 3. GStreamer（视频推流/接收）

README 4.3 的视频传输方案：

```bash
# 机载端推流（H.264，UDP 发往地面站）
gst-launch-1.0 v4l2src device=/dev/video0 ! video/x-h264,width=1280,height=720,framerate=30/1 ! \
  h264parse ! rtph264pay ! udpsink host=地面站IP port=5000

# 地面站接收
gst-launch-1.0 udpsrc port=5000 ! application/x-rtp,encoding-name=H264 ! \
  rtph264depay ! h264parse ! avdec_h264 ! autovideosink
```

这是第二阶段（无人机视觉识别）的核心链路，目标是**延迟 <200ms**。

## 4. YOLO 检测怎么接进来

```text
视频帧 ──▶ YOLO 检测 ──▶ 框出目标 ──▶ 结合 GPS/光流算坐标 ──▶ 下发给地面站/机器人
```

- 模型先用预训练 `yolov8n.pt` 验证流程，再换谢啸训练的豆荚螟模型
- 树莓派/机载算力有限，可用辅码流 + 小模型；或把视频传地面站用 GPU 推理
- 检测结果 + 无人机位姿 → 目标全局坐标（与杨梦享、马晨轩对接）

## 5. 常见问题排查

| 现象 | 可能原因 | 排查/解决 |
|------|----------|-----------|
| 拉不到流 | 数传未连/URL 错 | 先 VLC 验证；确认摄像头通电 |
| 画面很卡 | 用了主码流/带宽不够 | 换辅码流；降低分辨率 |
| 延迟 >200ms | 编码/传输环节多 | 用 H.264+UDP；避免多级转发 |
| YOLO 检测不到 | 模型类别名不对/画面模糊 | 打印类别名；提高清晰度 |
| 推理太慢 | 算力不足 | 用辅码流/小模型/地面站推理 |
