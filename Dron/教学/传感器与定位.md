# 传感器与定位 教学文档

## 1. 无人机怎么"知道"自己在哪

把多个传感器合起来看：

| 传感器 | 测什么 | 类比 |
|--------|--------|------|
| 陀螺仪（BMI055/ICM-42688-P） | 角速度 | 身体转多快 |
| 加速度计（同芯片） | 线加速度（含重力） | 身体往哪加速 |
| 罗盘 IST8310 | 地磁场方向 | 指南针 |
| 气压计 MS5611 | 大气压力 → 高度 | 海拔表 |
| GPS M8N | 绝对经纬度/高度 | 地图定位 |
| 光流模组 | 地面图像移动速度 | 看地面来判断自己在动 |

## 2. 姿态估计：为什么需要融合

陀螺仪快而准，但会**累积误差**（漂移）；加速度计不漂移但**噪声大**。
所以把两者融合：用加速度计修正陀螺仪的漂移，得到可靠的姿态（俯仰/横滚/航向）。

常用的融合算法是**卡尔曼滤波**：先根据模型"预测"，再用传感器测量值"更新"，
反复迭代，误差越来越小。

> 这就是为什么校准陀螺仪时要保持静止、校准加速度计要按提示摆放——给算法
> 一个准确的"初始参照"。

## 3. GPS 定位原理

GPS 靠**三角测量**：同时接收多颗卫星信号，根据信号到达时间差计算距离，
多颗卫星的距离球面相交，得到位置。所以：

- **卫星数越多越准**，室外飞行要求 ≥15 颗
- 室内收不到 GPS，要靠光流
- 本机悬停精度：GPS 垂直±0.5m、水平±0.8m

## 4. 光流：室内/低空定位

光流摄像头拍地面，比较相邻帧图像的移动，算出像素速度 → 机体速度。
特点：

- 输出的是 **xy 速度**，没有绝对位置（位置靠积分，会漂移）
- 低空（约 5m 以内）有效，越高精度越差
- 飞控会做**姿态补偿**和 **yaw 旋转补偿**，消除"原地晃却误报移动"的问题

检查方法：QGC → MAVLink 检测 → `current_distance` 是雷达高度；
光流 x/y 数据在滚转/前后移动时应有对应曲线变化。

## 5. RTK：厘米级定位（进阶）

RTK（实时动态差分）：

```
基准站（已知精确坐标）──数传──▶ 移动站（无人机）
两边收到同一组卫星信号，算相位差 → 厘米级定位
```

本机 RTK 悬停精度：垂直±0.1m、水平±0.15m。代价：成本高、依赖基站、
对环境（遮挡）敏感。

## 6. 常见问题排查

| 现象 | 可能原因 | 排查/解决 |
|------|----------|-----------|
| GPS 星数少/不定位 | 室内或遮挡 | 到室外开阔处，等待锁定 |
| 定点漂移大 | GPS 精度限制或未校准 | 校准罗盘/地平线；确认卫星数 |
| 室内无法定点 | 无 GPS | 依赖光流，光线要充足 |
| 光流数据异常 | 传感器脏/高度过高 | 擦拭镜头；保持 5m 以内 |
| 仪表盘姿态与实际不符 | 传感器未校准 | 重新校准罗盘/陀螺仪/加速度计/地平线 |
