# 地面机器人开始配置（SpiderPi Pro 第一步：开机与连接）

> 对应 README「第二阶段：地面机器人开发」的**第一步：基础环境配置**。
> 目标：让 SpiderPi Pro 正常开机，电脑能通过 VNC 连上树莓派桌面，并熟悉 `~/spiderpi` 源码目录结构，为下一步的六足行走与机械臂调试打基础。

> 开发按步骤推进，不按周排期：完成这一步并验收后，立即进入下一步。

## 1. 本步目标与验收标准

| 检查项 | 验收标准 |
|--------|----------|
| 机器人开机 | 扩展板 LED 正常指示，蜂鸣器鸣叫，机器人摆出立正姿态 |
| 热点连接 | 电脑可搜索到 `HW` 开头的热点并成功连接 |
| VNC 远程桌面 | 输入 `192.168.149.1` 可进入树莓派桌面 |
| 目录熟悉 | 能说出 `~/spiderpi` 下各目录用途，找到对应玩法文件 |
| 环境验证 | 能通过终端运行一个基础玩法（如动作组调用）并看到机器人动作 |

## 2. 认识 SpiderPi Pro

SpiderPi Pro 是以树莓派主板 + 扩展板为主控的 AI 视觉六足机器人套件，在六足底盘上增加了 5DOF 视觉机械臂，可扩展物品识别抓取、运输搬运、智能分拣、群控等玩法。

| 组成 | 说明 |
|------|------|
| 主控 | 树莓派主板（实测到货为 Pi5/8GB，Debian 12，Python 3.11；README 曾标 4B/4GB，连接方式一致） |
| 六足底盘 | 18 个总线舵机驱动的六足结构，可全向行走、适应地形 |
| 机械臂 | 5 自由度（5DOF），20kg·cm 总线舵机，可覆盖毛豆底荚（离地 7-11cm）作业区 |
| 单目相机 | 用于颜色识别、位置校准、目标抓取等视觉玩法 |
| 传感器 | 超声波传感器（避障）、IMU 姿态传感器 |
| 扩展板 | 舵机/传感器接口板，含充电口、电源开关、LED 状态灯、KEY 按键 |

## 3. 充电与开机

### 3.1 充电

1. 检查电池对接线：红对红、黑对黑
2. 充电器插入机器人背部扩展板的充电孔
3. 未通电时充电器指示灯为绿色；通电后变红表示正在充电（约 3 小时）
4. 指示灯变回绿色表示充满，**充满后尽快拔掉充电器，不要长时间挂着**

机器人尾部有电压显示模块：

- 工作电压范围：9V-12.6V
- 电压低于 10V 时应及时充电

### 3.2 开机

1. 将扩展板开关由 `OFF` 推至 `ON`
2. 扩展板 LED1、LED2 先常亮，稍等片刻 LED2 变为每 1 秒闪烁一次
3. 蜂鸣器鸣叫一次，机器人执行立正姿态，即为开机成功
4. 树莓派本身就是电脑，开机启动需要时间，请耐心等待 1-2 分钟

开机成功后机器人进入出厂默认的 **AP 直连模式**，会生成一个以 `HW` 开头的 Wi-Fi 热点（默认密码 `hiwonder`）。

## 4. 连接机器人

### 4.1 方式一：电脑 VNC 直连（推荐，本阶段必做）

VNC 是图形化远程控制软件，连上后可看到树莓派桌面、打开终端、查看和修改玩法代码。后续所有开发都在这个桌面上进行。

**第一步：安装 VNC Viewer**

资料包已附带安装包（`2 软件工具/3.远程连接工具/2.VNC（可视化桌面工具）/`）：

- Windows：[VNC-Viewer-6.17.731-Windows.exe](../GroundRobot/资料/SpiderPi%20Pro六足机器人专业开发套件/2%20软件工具/3.远程连接工具/2.VNC（可视化桌面工具）/Windows版本/VNC-Viewer-6.17.731-Windows.exe)
- Mac：[VNC-Viewer-7.7.0-MacOSX-universal.dmg](../GroundRobot/资料/SpiderPi%20Pro六足机器人专业开发套件/2%20软件工具/3.远程连接工具/2.VNC（可视化桌面工具）/Mac版本/VNC-Viewer-7.7.0-MacOSX-universal.dmg)

> Windows 安装时语言选 English，一路 Next 即可；Mac 版双击 dmg 拖入应用程序即可。

**第二步：连接机器人热点**

1. 打开电脑 Wi-Fi，搜索以 `HW` 开头的热点（如 `HW-XXXX`）
2. 连接该热点，密码：`hiwonder`

**第三步：VNC 登录树莓派桌面**

1. 打开 VNC Viewer，在地址栏输入：`192.168.149.1`，回车
2. 若提示非安全连接（Not secure），点击 `Continue`
3. 输入账号密码：

| 项目 | 值 |
|------|-----|
| Username | `pi` |
| Password | `raspberrypi` |

> SpiderPi Pro 无论树莓派是 4B 还是 Pi5 版本，账号密码均为 `pi` / `raspberrypi`。
> （只有 TurboPi、MasterPi、ArmPi mini 三款才区分主控版本：4B 为 `pi`/`raspberry`，Pi5 为 `pi`/`raspberrypi`。）

4. 勾选记住密码，点击 OK，即可看到树莓派桌面
5. 桌面上若弹出树莓派特性警告对话框，点“确定”关闭
6. 若出现黑屏只有一个鼠标，重启树莓派再试

### 4.2 方式二：手机 APP 试玩（可选）

想快速体验玩法可安装幻尔官方 APP **WonderPi**（iOS 在 App Store 搜索；安卓安装包在官方课程网 https://www.hiwonder.com.cn 软件下载 → APP 页面）。

1. 打开 APP，进入对应产品页，点击右下角 `+` 选择“直连模式”
2. 点击“去连接设备热点”，手机会跳转到 Wi-Fi 设置，连接 `HW` 开头热点（密码 `hiwonder`）
3. 返回 APP 即可看到机器人图标，进入模式选择界面试玩

> 注意：iOS 需等手机状态栏出现 Wi-Fi 图标再返回 APP；提示“网络不可用，是否继续连接”时点“保持连接”。

## 6. 环境验证：跑通第一个玩法

所有玩法程序都在**树莓派**上运行（通过 VNC 打开的终端），不是在自己电脑上运行。

### 6.1 动作组调用（推荐先做，不依赖摄像头）

```bash
python3 ~/spiderpi/functions/action_group_control_demo.py
```

运行后机器人会依次执行动作组（立正、前进、后退等），能正常动作即说明舵机、扩展板、主程序链路正常。

> ⚠️ **已知坑（Pi5/Bookworm 实测）**：官方
> `action_group_control_demo.py` 里 `turn_right_low` 用的是 `times=0`（无限循环），
> 而停止它靠的 `stop_servo()` 只发硬件停止指令、**不会置位软件停止标志**，导致机器人
> 一直右转停不下来；且 SDK 里 `self.stop_action_group` 与方法同名，会让第一个
> `stand_low` 被跳过。**建议不要直接跑官方 demo，改用下面“逐个动作跑一遍”的方式验证。**

**推荐验证脚本（每个动作只做一遍、不会死循环，最后自动立正复位）：**

```python
# 在树莓派终端执行（可直接粘到 python3 - 里，或存成文件后 python3 运行）
import time
from common.ros_robot_controller_sdk import Board
from common.action_group_controller import ActionGroupController

board = Board()
agc = ActionGroupController(board)
seq = ['stand_low', 'go_forward_low', 'back_low',
       'turn_left_low', 'turn_right_low', 'stand_low']
for name in seq:
    print('RUN', name)
    agc.run_action(name)   # run_action 跑一遍；不要用 times=0 的循环
    time.sleep(1.0)
agc.stop_servo()
```

> 想试更复杂的动作，`~/spiderpi/action_groups/` 里还有 `wave`（挥手）、
> `wave_and_grip`（挥手夹取）、`kick`（踢腿）、`twist`（扭动）、`dance`（跳舞）、
> `go_forward_and_grip`（前进夹取）等，把上面 `seq` 换成对应名字即可。
> `stand_flip` 会翻转机器人，勿在桌面/狭小空间运行。

### 6.2 颜色识别（视觉链路验证）

```bash
python3 ~/spiderpi/functions/color_detect.py
```

在摄像头前放一个色块，画面中能框出目标并显示坐标即通过。

### 6.3 管理开机自启服务

`SpiderPi.py` 开机自启由 systemd 服务 `spiderpi.service` 管理（自启文件 `/etc/systemd/system/spiderpi.service`）：

```bash
sudo systemctl stop spiderpi      # 本次关闭主程序
sudo systemctl start spiderpi     # 本次开启主程序
sudo systemctl disable spiderpi   # 永久关闭自启
sudo systemctl enable spiderpi    # 永久开启自启
```

> 调试玩法时建议先 `sudo systemctl stop spiderpi`，避免开机自启的主程序与手动运行的程序抢占舵机/摄像头资源。

## 7. 网络配置（为联调做准备）

机器人出厂默认为 **AP 直连模式**（机器人开热点，电脑连机器人）。这种模式不能访问外部网络。

**STA 局域网模式**（机器人主动连接路由器 Wi-Fi，可上网、可多设备通信）是后续地面站/机器人联调的必需配置。两种模式玩法功能完全一致。

### 7.1 修改热点名称/密码（直连模式）

```bash
cd ~/hiwonder-toolbox/
vim wifi_conf.py
```

修改 `WIFI_AP_SSID` 和 `WIFI_AP_PASSWORD`（如改为 `HW-Robot` / `hiwonder`），保存后：

```bash
sudo systemctl restart wifi.service
```

### 7.2 切换为 STA 局域网模式

```bash
cd ~/hiwonder-toolbox/
vim wifi_conf.py
```

1. 将 `WIFI_MODE` 改为 `2`（`1`=直连，`2`=局域网，`3`=直连共享）
2. 设置 `WIFI_STA_SSID` 和 `WIFI_STA_PASSWORD` 为路由器 Wi-Fi 名称和密码（建议选 5G 信号，传输速率更高）
3. 保存后重启 Wi-Fi 服务：

```bash
sudo systemctl restart wifi.service
```

局域网模式下，在路由器管理页面（或手机 APP 长按机器人图标）可查到机器人分配到的 IP，VNC 用该 IP 连接。

想切回直连模式：把所有配置行注释掉再保存并重启服务，或长按扩展板 `KEY1` 按键直到蓝灯闪烁。

> 联调建议：在路由器 DHCP 中为地面站、SpiderPi Pro、F410 各绑定固定 IP（README 地面站文档也有同样建议）。

> ⚠️ **Pi5/Bookworm 实测**：这台机器的 Wi-Fi 由 **NetworkManager** 管理（`nmcli`），
> 不是 hiwonder 的 `wifi.service`。`wifi_conf.py` 里的变量实际是 `WIFI_MODE` /
> `WIFI_STA_SSID` / `WIFI_STA_PASSWORD`（不是 `HW_WIFI_*`），且改它不一定生效。
> 直接连 Wi-Fi 请用桌面右上角网络图标或 `nmcli`；查当前连接用
> `nmcli connection show --active`，查 IP 用 `hostname -I`。

## 9. 常见问题

**Q：电脑搜不到 `HW` 开头的热点？**

确认机器人已开机完成（LED2 闪烁），再刷新 Wi-Fi 列表；若刚开机，等待 1-2 分钟再搜索。

**Q：VNC 提示“非安全连接”？**

这是树莓派 VNC 证书提示，点击 `Continue` 继续即可。

**Q：VNC 连不上 / 密码对还是进不去？**

SpiderPi Pro 账号固定 `pi` / `raspberrypi`（热点密码是 `hiwonder`，别和登录密码混）。
Pi5/Bookworm 的桌面是 Wayland，VNC 由 `wayvnc` 提供（监听 **5900**），不是旧的 RealVNC
`vncserver-x11-serviced`。确认 `systemctl is-active wayvnc` 为 `active`；VNC Viewer
地址填机器人 IP（直连 `192.168.149.1`，局域网填 DHCP 分配到的 IP，如 `10.194.228.89`）。

**Q：VNC 登录密码错误？**

SpiderPi Pro 固定为 `pi` / `raspberrypi`。只有 TurboPi、MasterPi、ArmPi mini 才按主控版本区分（4B 为 `raspberry`）。

**Q：VNC 进去黑屏，只有一个鼠标？**

树莓派桌面未能正常加载，重新启动树莓派再连接。

**Q：树莓派 5 红灯常亮无法开机（ACT 灯短闪 4 次）？**

说明引导程序丢失，按资料 `6 常见问题解答/树莓派5红灯常亮无法开机解决方法.pdf` 用官方烧录软件重新写入 Pi 5 的 SD Card Bootloader。

**Q：改了网络配置后机器人连不上热点？**

用有线方式或重新按 `KEY1` 切回直连模式；确认 `wifi_conf.py` 中 SSID/密码无空格、大小写正确，然后 `sudo systemctl restart wifi.service`。

**Q：运行玩法时提示设备被占用？**

先执行 `sudo systemctl stop spiderpi` 关闭开机自启的主程序，再手动运行玩法。

**Q：动作组 demo 一跑就一直转圈不停？**

官方 `action_group_control_demo.py` 里 `turn_right_low` 用 `times=0` 无限循环，
`stop_servo()` 不会置位软件停止标志，所以停不下来。改用第 6.1 节的 `run_action`
逐个动作脚本；若已经跑起来，用 `ssh` 连上执行停止/复位脚本，或直接给机器人断电重启。
