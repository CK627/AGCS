# 官方能力复用清单（SpiderPi Pro 地面机器人）

> 用途：快速查「哪些功能官方已提供、可直接调用，哪些我们已实现」，避免重复造轮子。
> 所有调用都在树莓派 `~/spiderpi` 环境下（先 `sudo systemctl stop spiderpi` 避免抢串口）。

## 一、动作组（挥手/举手/踢腿/跳舞等）——直接 `agc.run_action('名字')`

动作组是官方预录好的一串舵机姿势，存在 `~/spiderpi/action_groups/*.d6a`。

```python
from common.action_group_controller import ActionGroupController
agc = ActionGroupController(board)
agc.run_action('wave')            # 播放一次（推荐，不会死循环）
# agc.run_action_group('wave', times=2)  # 播多次；注意 times=0 是无限循环，慎用
```

| 动作组 | 含义 | 动作组 | 含义 |
|--------|------|--------|------|
| `stand_low / middle / high` | 低/中/高姿态立正 | `go_forward_low / middle / high` | 低/中/高姿态前进 |
| `back_low / middle / high` | 低/中/高姿态后退 | `turn_left_low / middle / high` | 低/中/高姿态左转 |
| `turn_right_low / middle / high` | 低/中/高姿态右转 | `left_move` / `right_move` | 左移 / 右移 |
| `wave` | **挥手/举手（反馈用）** | `wave_and_grip` | 挥手+夹取 |
| `kick` | 踢腿 | `dance` | 跳舞 |
| `twist` / `twist_f` / `twist_l` | 扭身（前/左） | `stepping` | 原地踏步 |
| `attack` | 攻击 | `forward_flutter` / `back_flutter` | 前扑 / 后扑 |
| `go_forward_and_grip` | 前进+夹取放置 | `stand_flip` | 翻转（⚠️ 危险，别在桌面跑）|

> 已实测踩坑：官方 `action_group_control_demo.py` 里 `turn_right_low` 用 `times=0` 会无限转圈；
> 用 `run_action()`（单次）代替即可，见 [开始配置.md](开始配置.md) 第 6.1 节。

## 二、硬件控制（Board 方法，直接 `board.xxx()`）

```python
from common.ros_robot_controller_sdk import Board
board = Board()
```

| 方法 | 用途 | 示例 |
|------|------|------|
| `board.set_buzzer(freq, on, off, repeat)` | 蜂鸣器 | `board.set_buzzer(2000, 0.05, 0.15, 1)` |
| `board.set_rgb(pixels)` | RGB 灯 | `board.set_rgb([[1,255,0,0], [2,0,255,0]])` |
| `board.set_led(on, off, repeat, led_id)` | LED 灯 | `board.set_led(0.1, 0.2, 3, 1)` |
| `board.bus_servo_set_position(dur, [[id,pulse],...])` | 总线舵机(机械臂21-25) | `board.bus_servo_set_position(1, [[21,500],[22,507]])` |
| `board.bus_servo_stop(ids)` | 停总线舵机 | `board.bus_servo_stop([21,22,23,24,25])` |
| `board.pwm_servo_set_position(dur, [[id,pulse],...])` | PWM 舵机(1,2号) | — |

> ⚠️ `bus_servo_read_position()` 在本机扩展板返回 None（读不到物理脉宽），**只能写、不能读**。

## 四、六足运动（`kinematics.IK`）

```python
import kinematics
ik = kinematics.IK(board)
ik.stand(ik.initial_pos)                       # 立正
ik.go_forward(ik.initial_pos, 2, 50, 80, 1)    # 前进 50mm
ik.back(ik.initial_pos, 2, 100, 80, 1)         # 后退 100mm
ik.turn_left(ik.initial_pos, 2, 30, 100, 1)    # 原地左转 30°
ik.turn_right(ik.initial_pos, 2, 30, 100, 1)   # 原地右转 30°
ik.left_move(ik.initial_pos, 2, 100, 100, 1)   # 左移 100mm
ik.right_move(ik.initial_pos, 2, 100, 100, 1)  # 右移 100mm
```

参数顺序：`(姿态, 模式2=六足, 步幅mm或角度°, 速度, 次数)`。

## 五、机械臂（ArmIK）

```python
import arm_ik.arm_move_ik as AMK
ak = AMK.ArmIK()
ak.setPitchRangeMoving((x, y, z), 俯仰角, 俯仰下限, 俯仰上限, 时间)
```

> ⚠️ **本机 IK 与实物有偏差**：用 IK 算出的位置和机械臂实际位置对不上。
> 复位/抓取请优先用现场标定好的**固定脉宽**（`config/robot_params.yaml` 的 `arm.reset_pulses` 等），
> 不要依赖 IK 算坐标。我们已封装 `make_arm_ik()`（在 `functions/robot_config.py`）做方向校正。

## 九、已验证可用的「反馈」组合（直接拼）

检测到目标后做反馈，下面都是现成的：

```python
agc.run_action('wave')                                   # 1. 举手/挥手
board.set_buzzer(2000, 0.05, 0.15, 1)                    # 2. 蜂鸣
ultrasonic.set_rgb(1, (255, 0, 0))                       # 3. 超声波模块上的 RGB 灯
board.set_rgb([[1, 255, 0, 0]])                          # 4. 扩展板 RGB
```

> 注意：机械臂串口 `/dev/ttyAMA0` 同一时间只能一个进程占用；运行我们自己的程序前先
> `sudo systemctl stop spiderpi`，并确保 `joystick.service` 等不抢占（本机已处理）。
