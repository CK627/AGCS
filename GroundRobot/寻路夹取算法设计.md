# 地面机器人「检测 → 追踪 → 夹取」完整算法设计

> 实际目标：毛豆上夹虫子（豆荚螟）；当前阶段用红/绿/蓝/黄方块调试。
> 核心原则：**摄像头用云台(21/24) PID 实时锁定目标，保持抬头**；距离用**超声波 + 像素转坐标双信号**；夹取用官方 `intelligent_fetch` 参数；每个阶段都有目标丢失的保底机制。

## 一、整体状态机（if 线）

```
START
  │
  ▼
初始化（相机/机械臂复位/超声波/点阵，机械臂到抬头检测姿态 (10,15,30) pitch=0）
  │
  ▼
① 检测发现目标
  │  取帧 → detect_color 检测
  ├─ 检测到 ──────────► ②
  └─ 检测不到 → 云台扫描(21逐点+24上下) → 仍没有 → 六足转身 → 回到①（最多 N 轮）
  ▼
② 云台 PID 追踪（cx→320, cy→240，摄像头一直盯着）
  │  每帧检测
  ├─ 目标丢失(连续3帧) → 保底：后退找回 → 重扫 → 转身找 → 仍丢则回①/失败
  └─ 稳定 ────────────► ③
  ▼
③ 距离判断（双信号）
  │  超声波 dist_cm + 像素转坐标 (x,y)
  ├─ 够近（超声波<=near_cm 或 10<=y<=18）► ⑤
  ├─ 远  → ④ 前进
  └─ 贴底/障碍物(超声波<=避障阈值) → 停止前进 → ⑤（抬头夹取）
  ▼
④ 逼近（六足走路）
  │  距离远→前进(大步x2/小步x2)、横向偏→转身、超声波避障
  └─ 回到③
  ▼
⑤ 夹取（机械臂）
  │  抬头稳定检测 → 距离确认 → 机械臂伸 (x, y+2, -5) 向下夹 → 抬起 → 放置
  ▼
⑥ 夹取验证（x/y 距离中位数 / 目标消失位移）
  ├─ 成功 → 完成
  └─ 失败 → 重试（换姿态/后退）→ 超过次数 → 放弃
```

## 二、各阶段详细 if 线

### ① 检测发现目标
- 输入：一帧 BGR 图。
- `detect_color()`：LAB 阈值 → 轮廓 → 最大轮廓中心 (cx, cy) + 面积。
- if 面积 >= min_area → 检测到目标，返回 (cx, cy, area, contour)。
- else → 未检测到 → 云台扫描（21 脉宽逐点 + 每个点 24 上下扫）→ 每点检测一次。
- 扫描一圈仍无 → 六足转身 turn → 回到扫描，最多 scan_rounds 轮。

### ② 云台 PID 追踪（一直盯着目标）
- 检测到目标后，用 `x_pid`（cx→320）、`y_pid`（cy→240）驱动舵机 21/24。
- **保持抬头**（24 舵机不低头），避免高处目标贴底。
- if 连续 3 帧检测不到目标 → 目标丢失保底：
  1. 先恢复上次云台位置重检；
  2. 仍无 → 重扫（21+24 双轴）；
  3. 仍无 → 后退一小步 / 转身找；
  4. 仍无 → 回到①重新搜索。

### ③ 距离判断（双信号，不靠面积估距）
- 超声波 `dist_cm()`：实测 cm。
- 像素转坐标 `pixel_to_arm_coord(cx,cy)` → (x, y)。
- 两者互证：视觉估距与超声波差 > ultra_match_cm → 弃用超声波，退回视觉。
- if 超声波 <= near_cm(15) → 够近，进⑤。
- elif 超声波 <= 避障阈值(约10) 或目标贴底 → 前面有障碍物/已贴近 → 停止前进，进⑤（抬头夹取）。
- else → 远，进④前进。

### ④ 逼近（走路，带避障）
- if 距离远 → 前进（>fine_cm 走大步 70mm，否则小步 40mm，连续 x2）。
- if 目标横向偏（cx 偏离 320 超阈值）→ 转身（turn_sign 方向）。
- if 超声波 <= 避障阈值 → 停止前进（不撞障碍物）。
- 每步后回到③重新判断。

### ⑤ 夹取（机械臂，只动 21-25）
- 抬头稳定检测目标（不切 -90 低头）。
- 距离确认：像素转坐标 (x, y) 落在可及范围（|x|<=8, 6<=y<=24）才伸臂。
- 高度：目标在高处时，先用「抬头检测 + 固定夹取点」，不用 -90 的地面标定映射。
- 夹取动作（官方 intelligent_fetch）：
  `setPitchRangeMoving((x, y+2, -5), -90, -90, 100, 2)` → 夹爪 600 闭合 → 抬起 `(x,y,8)` → 放置 `(12,24,-5)` → 松开 → 回检测位。

### ⑥ 夹取验证（目标丢失 / 距离中位数）
- 夹取后多次检测：
  - if 目标消失（detect 返回 None）→ 夹到。
  - elif 目标中心 x/y 与夹取前位移超过阈值 → 夹到。
  - elif 多次检测 x/y 的中位数 < 阈值（目标被夹到爪边、离摄像头很近）→ 夹到。
  - else → 未夹到 → 重试（最多 attempts 次，重试前复位/后退）。

## 三、目标丢失的全局保底机制

| 丢失发生位置 | 保底动作 |
|-------------|---------|
| ① 检测阶段 | 云台扫描 → 转身 → 重新扫描 |
| ② 追踪阶段 | 恢复云台位 → 重扫 → 后退 → 转身 |
| ③④ 距离/逼近阶段 | 后退 → 重新追踪 |
| ⑤ 夹取阶段 | 重试伸臂 → 换抬头/低头策略 |
| 全局超时/轮数耗尽 | 报告失败 + 复位 + 状态置 0 |

## 四、机械臂可及范围（平滑理解）

| 轴 | 范围 | 超出处理 |
|----|------|---------|
| x | -8 ~ +8 cm | 转身 / 云台水平微调 |
| y | 6 ~ 24 cm | y>24 前进、y<6 后退 |
| z | -7 ~ 5 cm | 地面用 -5 向下夹、高处用固定夹取点 |

## 五、传感器分工

| 传感器 | 作用 |
|--------|------|
| 云台 21/24 + 相机 | 实时锁定目标、像素转坐标 |
| 超声波 | 实测距离、避障 |
| 点阵 | 状态显示（搜索/追踪/夹取/完成/失败） |

## 六、与现有 agcs_lib 的对应（哪些代码已有、哪些要补）

| 阶段 | 已有代码 | 要补 |
|------|---------|------|
| ① 检测 | `vision.detect_color`、`search.search()` | 无明显缺口 |
| ② 追踪 | `search._track`（PID）、`grab._rescan` | 保持抬头姿态、丢失保底链 |
| ③ 距离 | `sensors.dist_cm` | **search 里补调用超声波**（现在没用） |
| ④ 逼近 | `motion.go_forward/turn` | 补超声波避障 |
| ⑤ 夹取 | `grab._grab_once`（官方参数） | 高度分路（地面/高处） |
| ⑥ 验证 | `grab._verify` | 改成距离中位数判定 |
