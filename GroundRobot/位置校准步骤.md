# 位置校准步骤（camera_cal_main.py）
#
# 目的：重新计算「相机 ↔ 机械臂」的相对位置（R/T），写进 config/camera_cal.yaml 的
# block_params。只有这个标定对了，「像素坐标 → 机械臂夹取坐标」才准，否则夹子会夹空。
#
# 什么时候必须做：机械臂物理重装过（方向改过）之后，旧标定失效，必须重做。
#
# ## 一、准备 AprilTag 标定卡
#
# 1. 解压官方标签集合：
#    资料/1 教程资料/10.AI视觉识别与追踪课程/10.7 标签识别/10.7.3 ApirlTag标签集合（需解压）.rar
# 2. 里面是 tag36h11 家族的 AprilTag 图片，打印 id=1 的那张（尺寸约 33mm）。
# 3. 贴在一张平整硬卡纸上。
#
# ## 二、摆放
#
# - 机械臂立正，恢复到检测位 (0,15,5)（俯仰 -90°）。
# - 把 id=1 的 AprilTag 卡放在机械臂正下方地面，标签朝上、正对摄像头。
#
# ## 三、运行并自动保存
#
# 在 VNC 终端执行（先停掉所有抢资源的服务：主程序抢摄像头、摇杆抢串口）：
#
#     sudo systemctl stop spiderpi
#     sudo systemctl stop joystick
#     python3 ~/spiderpi/functions/camera_cal_main.py
#
# 运行后自动执行（约 30 秒，听蜂鸣器）：
#
# | 时间 | 动作 |
# |------|------|
# | 3 秒 | 蜂鸣 1 声，机械臂下降到 (0,15,-2) |
# | 再过 10 秒 | 蜂鸣 2 声，机械臂抬起到 (0,15,5) |
# | 再过 15 秒 | 蜂鸣 3 声，自动保存到 camera_cal.yaml |
#
# ## 四、验证
#
#     cat ~/spiderpi/config/camera_cal.yaml
#
# 确认 block_params 里的 R / T 已更新（不再是旧值）即成功。
#
# ## 五、校准完成后
#
# 回到「识别 → 夹取」：用官方 block_fetch.py 的标准流程
# （检测位 (0,15,5) 识别色块 → 像素转坐标 → 夹取），坐标就准了。
