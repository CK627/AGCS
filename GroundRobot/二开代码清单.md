# 地面机器人二开代码清单

> 对比基准：官方源码 `资料/SpiderPi Pro六足机器人专业开发套件/3 源码资料/spiderpi_pro/spiderpi/`
> 二开代码目录：`Code/`（与树莓派 `~/spiderpi` 目录结构一一对应）

## 二开代码（我们新增/修改的代码文件）

| 目录/文件 | 作用 |
| --------- | ---- |
| `functions/color_detect.py` | 颜色识别（**改写官方同名文件**，保留 `init/start/stop/exit/run` 接口，加 `--color` 参数并支持 yellow） |
| `config/robot_params.yaml` | 所有可调参数（目标颜色、步幅、避障阈值、机械臂/夹爪/复位脉宽、搜索、朝向对齐） |
| `functions/auto_fetch.py` | 自动接近夹取（俯仰扫描搜索 → 视觉居中 → 视觉夹取，超声波只在视觉看不到时兜底） |
| `functions/grab_block.py` | 单色方块夹取（稳定检测 → 朝向对齐可选 → 夹取 → 放下 → 复位） |
| `functions/obstacle_avoidance.py` | 超声波自主避障行走（基于官方 `avoidance.py` 二开） |
| `functions/robot_config.py` | 读参数文件 `load_params()` + 机械臂 IK 封装 `make_arm_ik()` |
| `functions/vision_utils.py` | 视觉公共工具（颜色检测、轮廓、像素→机械臂坐标、朝向角、畸变校正） |
| `functions/yolo_detect.py` | YOLO 检测器（虫识别接口，可替换颜色检测） |
| `functions/yolo_detect_onnx.py` | YOLO ONNX 本地推理（虫识别，约 3.6 FPS） |
| `kinematic_routines/arm_pick.py` | 机械臂逆运动学抓取封装（夹爪=舵机25，基于官方 `block_fetch.py` 重构） |
| `advanced/autonomous_pick.py` | 整合状态机（收任务→导航→扫描→对准→接近→抓取，含 HTTP/推流） |
| `communication/__init__.py` | 通信模块包标记 |
| `communication/task_server.py` | 地面站↔机器人 HTTP 服务（`POST /task` 收任务、`GET /status` 上报、`/video.mjpeg` 推流） |
| `models/worm_best.onnx` | 虫识别 ONNX 模型（测试集 mAP50 0.89） |
| `sync_to_robot.sh` | 把本地代码同步到树莓派 `~/spiderpi` |
| `pull_from_robot.sh` | 把树莓派配置/SDK 拉回本地备份 |
